# CSJ Parkings

Sistema de reserves de places als pàrquings municipals de Tarragona.
Projecte d'ASIX2 · **Equip:** Carlos Xavier, Sara Pulido i Joel Zurita.

Tot el projecte és a la carpeta [`proyecto_parking/`](proyecto_parking/):

| Carpeta | Contingut |
|---|---|
| [`app_php/`](proyecto_parking/app_php/) | Aplicació web (PHP 8.1 + MariaDB, patró MVC) |
| [`database/`](proyecto_parking/database/) | Scripts SQL: estructura (`schema.sql`) i dades inicials (`seed.sql`) |
| [`infra/`](proyecto_parking/infra/) | Scripts d'instal·lació dels servidors (RAID, LAMP, SSL, còpies, monitoratge, desplegament) |
| [`docs/sprint1/`](proyecto_parking/docs/sprint1/) | Lliurament del Sprint 1: anàlisi i disseny |
| [`docs/sprint2/`](proyecto_parking/docs/sprint2/) | Lliurament del Sprint 2: documentació tècnica, manual d'usuari, planificació i presentació |

Més detalls a [`proyecto_parking/README.md`](proyecto_parking/README.md).
